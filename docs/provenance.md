# Происхождение и лицензирование

Дата проверки: 2026-11-24. Новый код лицензирован MIT, текст в корневом LICENSE.

Переносимый код взят из `https://github.com/averichev/mockport`, commit
`e8705bceffc34d047023af4970997af8453ddf58`. Корневой Cargo.toml источника явно
указывает `license = "MIT"`. Отдельного корневого LICENSE в этом commit нет:
это зафиксированное ограничение исходной документации, а не основание приписывать
код другому проекту или другой лицензии.

История указанных updater-модулей, тестов и документации содержит одного автора:
`averichev <averichev@yandex.ru>`. Основные исходные commits:

- `6a36b9e` — первоначальная безопасная standalone-реализация;
- `5aaab8b` — supervisor/runtime и включение обновлений из интерфейса.

Сопоставление переносимых модулей находится в audit.md. Скопированы и адаптированы
только собственные updater-модули и соответствующие проверки. В crate не входят
frontend, SQLx migrations, MockPort business logic, встроенные assets,
`mockport-test-data`, Faker и его отдельные лицензированные данные.

Приватные ключи, production-конфигурация обновлений, продуктовый UUID MockPort,
публичный production-ключ и домены рабочего источника не переносились.
Тестовые ключи: фиксированные seed bytes в Rust-тестах и одноразовый OpenSSL key
в E2E. README содержит публичный контрольный JWK из RFC 8037; это не рабочее доверие.

Протокол v1 используется по внешней спецификации без копирования её текста:
`averichev/releases/docs/integrations/standalone-protocol.md`, прочитанный blob SHA
`9b66f53ef3d1819994bae37ab9a0951dc7d7027d`. Литерал
`releases-standalone+jws` обязателен этим протоколом; это не привязка к серверу.

Внешние Rust-зависимости подключаются через Cargo, их исходники не копируются
в репозиторий. Их лицензии и точные версии доступны через Cargo metadata/lock.
Обновление версий ed25519-dalek/sha2/base64 не меняет bytes-to-sign; совместимость
проверяется исходными тестами и отдельным OpenSSL signer в E2E.

Владелец запросил выделение в MIT crate и затем явно разрешил публичный GitHub
для подключения другими Cargo-проектами. Проверка происхождения выше основана
на истории и MIT metadata источника; отсутствие корневого исходного LICENSE
раскрыто явно. Перед stable release/crates.io остаются отдельная проверка лицензии,
security review и обратная интеграция. Эта задача не создаёт release/tag/crates.io.
