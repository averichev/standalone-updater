# Архитектура

`standalone-updater` — универсальный клиент подписанных обновлений. Совместимость
с источником определяется форматом HTTP-ответов и подписанных метаданных.
Приложение задаёт полные URL и доверенный ключ. Домены, схемы путей и регистрация
в конкретном сервисе публикации относятся к интеграции приложения.

Для внедрения и локальных проверок используй тестовый источник. Параметры рабочего
канала бери из доверенной конфигурации приложения, когда задача требует проверки
его реальных выпусков.
